# 🤝 CONTRIBUTING — Traje Volador EDF+RCS

Bienvenido al proyecto. Buscamos feedback técnico
y colaboradores en estas áreas:

## ¿Cómo contribuir?

### 🐛 Reportar un fallo técnico
1. Ve a la pestaña **Asuntos** (Issues)
2. Clic en **Nuevo asunto**
3. Describe el fallo con detalle

### 💡 Sugerir una mejora
1. Ve a **Asuntos** → **Nuevo asunto**
2. Etiqueta: `mejora`
3. Describe tu propuesta

## Áreas donde necesitamos feedback

- Sistema energético (batería + H₂)
- Cálculo de empuje EDF
- Sistema RCS
- Código IA (ROS2)
- Viabilidad del presupuesto

## Contacto
GitHub Issues es el canal principal.
